# Milk VPN

Готовый сервис продажи VPN-доступа: **сайт**, **Telegram-бот**, **личный кабинет**, **админ-панель**, оплата через **ЮKassa**, управление несколькими **серверами 3x-ui в разных странах** и **реферальная программа**.

## Возможности

**Для пользователей**
- Сайт: лендинг с тарифами и локациями, инструкция по подключению, FAQ, страницы условий.
- Бот: покупка и продление, пробный период, ключи, QR-код, уведомления об окончании, «Пригласить друга».
- Личный кабинет (вход по одноразовой ссылке из бота): ключи, трафик, QR, история платежей, реферальная ссылка и статистика.
- Одна ссылка-подписка `/sub/…` — все страны сразу, приложение обновляет список само.

**Для владельца**
- Админ-панель: серверы по странам, тарифы (с удалением), пользователи с персональными ценами и скидками, ключи, заказы, рассылка, расширенные реферальные настройки, статистика.
- Несколько VPN-серверов (3x-ui) — ключ создаётся на всех, новый сервер подхватывает все действующие ключи.
- Реферальная программа: награда днями или % от тарифа, бонус и скидка приглашённому, лимиты, срок, минимальная сумма, бонус за каждого N-го друга, личные условия для партнёров.
- Поддержка 3x-ui 2.x и 3.x (включая вход по API-токену).
- ЮKassa: статус и сумма платежа перепроверяются запросом в API ЮKassa (а не берутся из уведомления), обработка идемпотентна; если серверы недоступны — платёж подтвердится позже (повтор уведомления + фоновая сверка).
- Установка одной командой на VPS, автоматический HTTPS, ежедневные бэкапы.

## Установка

```bash
sudo bash deploy/install.sh
```

Подробная инструкция — **[docs/INSTALL.md](docs/INSTALL.md)**. Подготовка VPN-серверов — [docs/NODES.md](docs/NODES.md). Работа с админкой — [docs/ADMIN.md](docs/ADMIN.md).

## Запуск локально (для разработки)

```bash
cp .env.example .env            # заполнить SECRET_KEY, ADMIN_PASSWORD, BOT_TOKEN
python -m venv .venv && .venv\Scripts\activate    # Linux/macOS: source .venv/bin/activate
pip install -r requirements.txt
uvicorn app.main:app --port 8000
```

Сайт — `http://localhost:8000`, админка — `/admin`. Уведомления ЮKassa на localhost не придут (её серверу не достучаться), но после оплаты статус подтянется при возврате на сайт — для проверки платежей нужен публичный HTTPS-адрес.

Тесты: `pip install -r requirements-dev.txt && pytest`.

## Структура

```
app/
  main.py       запуск: БД, миграция, настройки, фоновые задачи, бот
  config.py     переменные окружения (.env)
  models.py     User, Plan, UserPrice, Server, Key, KeyServer, Order, ReferralReward, Setting
  services.py   выдача/продление ключей на всех серверах, подписка, заказы, рефералка, синхронизация
  xui.py        клиент API 3x-ui + сборка vless-ссылок
  payments.py   ЮKassa: создание платежа, проверка статуса
  runtime.py    настройки из админки (рефералка, пробный период)
  crypto.py     шифрование паролей серверов
  bot.py        Telegram-бот
  web.py        сайт, кабинет, /sub, callback'и Робокассы
  admin.py      админ-панель
  templates/    HTML (Jinja2)      static/   CSS/JS/favicon
deploy/         install.sh, install-node.sh, update.sh, backup.sh
docs/           INSTALL.md, NODES.md, ADMIN.md
tests/          pytest
```

## Безопасность

- Сервис не стартует без `SECRET_KEY` (≥16 символов) и `ADMIN_PASSWORD` (≥8).
- CSRF-токены на всех POST-формах; ограничение попыток входа в админку; cookie сессии `HttpOnly`, `SameSite=Lax`, `Secure` при https.
- Подписи Робокассы сравниваются в постоянное время; сумма платежа сверяется с заказом.
- Пароли панелей 3x-ui хранятся зашифрованными.
- `/docs` и OpenAPI отключены. Админку лучше дополнительно закрыть по IP на уровне прокси.

## Ограничения

- Поддерживаются клиенты **VLESS** (inbound других протоколов в подписку не попадают); панель 3x-ui без двухфакторной аутентификации.
- Лимит трафика и устройств применяется каждой панелью отдельно.
- Один процесс (бот на long polling). SQLite по умолчанию; для PostgreSQL — `pip install asyncpg` и `DATABASE_URL=postgresql+asyncpg://…`.
- Типовые тексты «Условия» и «Конфиденциальность» нужно проверить и доработать под ваш бизнес и законодательство.
