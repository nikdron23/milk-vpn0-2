1. Общие положения

{{ cfg.brand_name }} (далее — «Сервис») предоставляет доступ к VPN-соединению по платной подписке. Используя Сервис, вы соглашаетесь с настоящими условиями.

2. Подписка и оплата

  • Доступ предоставляется на срок и с лимитами, указанными в выбранном тарифе.
  • Оплата производится через платёжного оператора (ЮKassa). Данные банковской карты Сервису не передаются и не хранятся.
  • Ключ выдаётся автоматически после подтверждения оплаты. При продлении новый срок прибавляется к оставшемуся.
  • Вопросы по возврату средств рассматриваются через поддержку{% if cfg.contact_email %} ({{ cfg.contact_email }}){% endif %}.

3. Правила использования

  • Запрещено использовать Сервис для действий, нарушающих законодательство, для рассылки спама, атак на сети и сервисы, а также для нарушения прав третьих лиц.
  • Ключ предназначен для личного использования; количество одновременных подключений может быть ограничено тарифом.
  • Запрещена перепродажа и публичное распространение ключей.

4. Ограничения и блокировка

Сервис вправе ограничить или отозвать ключ при нарушении этих условий. Мы стремимся к бесперебойной работе, но не гарантируем отсутствие сбоев и недоступности отдельных серверов или внешних сетей.

5. Изменения условий
